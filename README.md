# Gestión de Clínica (Aplicación Web)

Aplicación web desarrollada en C# con ASP.NET y SQL Server para la gestión integral de turnos, pacientes y médicos en una clínica. Este proyecto fue desarrollado en equipo durante la Tecnicatura Universitaria en Programación (UTN).

## Características Principales

* **Gestión de Pacientes:** Operaciones CRUD (Crear, Leer, Actualizar, Borrar) para pacientes.
* **Gestión de Médicos:** Administración de profesionales y sus especialidades.
* **Gestión de Turnos:** Asignación, modificación y cancelación de turnos.
* **Control de Acceso:** Sistema de Login con control de acceso basado en roles y permisos (Administrador, Recepcionista y Médico).
* **Validaciones:** Validaciones de datos en los formularios para asegurar la integridad de la información.
* **Notificaciones:** Envío de mail personalizado para notificar el estado del turno.

## Stack Tecnológico

Este proyecto fue construido utilizando las siguientes tecnologías:

* **Backend:** C#
* **Framework:** ASP.NET (Web Forms)
* **Base de Datos:** SQL Server
* **Acceso a Datos:** ADO.NET
* **Frontend:** HTML, CSS, Bootstrap
* **Control de Versiones:** Git y GitHub
